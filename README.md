# Movie-Rating-Predictions-
-Using Python, Pandas, Scikit-learn, Statsmodels I developed a predictive model to estimate movie ratings by performing Multiple Linear Regression on datasets involving budget, revenue, and critic scores.
-Executed comprehensive data cleaning and wrangling using Pandas and Regular Expressions, handling missing
values and removing outliers via the Interquartile Range (IQR) method.
– Conducted Exploratory Data Analysis (EDA) with Seaborn and Matplotlib to identify key correlations, such as
the 0.71 Pearson coefficient between major critic platforms.
– Optimized model accuracy by analyzing p-values and interaction terms, ensuring all final predictors met a p < 0.05
significance threshold.
– Validated statistical assumptions using Shapiro-Wilk and D’Agostino’s K-squared tests to ensure normality and
homoscedasticity of residuals.
